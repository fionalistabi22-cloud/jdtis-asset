Panduan Persediaan Sistem JTDIS Aset

Langkah-langkah Pemasangan:

1️⃣ Buka phpMyAdmin

Akses: http://localhost/phpmyadmin

2️⃣ Cipta Database Baru
  • Nama Database: jtdis_asset
  • Collation: utf8mb4_general_ci
  • Klik "Cipta"
3️⃣ Import Schema
  1. Pilih database jtdis_asset
  2. Pergi ke tab "Import"
  3. Pilih file: jtdis_asset.sql
  4. Klik "Go" / "Jalan"
4️⃣ Import Data Sampel
  1. Pilih database jtdis_asset
  2. Pergi ke tab "Import"
  3. Pilih file: setup_data.sql
  4. Klik "Go" / "Jalan"
✅ Selesai!

Anda boleh log masuk dengan:

  • Emel: admin@jtdis.gov.my
  • Kata Laluan: 12345678
Pergi ke Log Masuk
⚠️ Maklumat Penting
  • Pastikan MySQL/MariaDB sedang berjalan
  • Gunakan phpMyAdmin untuk import file SQL
  • Tukar kata laluan admin selepas log masuk pertama
